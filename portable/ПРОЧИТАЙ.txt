Чистильщик диска 2.1 — портативная версия, установка не нужна.

ЗАПУСК
  1. Распакуйте архив ЦЕЛИКОМ (папка «Чистильщик диска»), а не один файл.
  2. Двойной клик по «Запустить Чистильщик.bat».
     Откроется чёрное окно с адресом http://localhost:8770 (порт может быть другим),
     и сам откроется браузер с программой.
  3. Окно консоли не закрывайте — это и есть программа. Закрыли окно = программа выключилась.
     Если браузер не открылся — скопируйте адрес из окна в любой браузер.

  Windows может спросить «Не удаётся проверить издателя. Запустить?» — нажмите «Запустить».

ПОЧЕМУ НЕ .EXE
  Прошлая версия была одним exe, собранным PyInstaller. Защитник Windows ложно принял его
  за вирус (Trojan:Win32/Wacatac.B!ml — «!ml» значит догадка нейросети, а не найденный вирус).
  Теперь программу запускает официальный Python (python.exe с цифровой подписью
  Python Software Foundation) из папки app\runtime, а сама программа — открытый текст
  app\cleaner.py и папка app\ui. Ничего не прячется и не распаковывается во временные папки.

ПРИ ПЕРВОМ ЗАПУСКЕ
  Появится тест: что вы хотите почистить, какие программы трогать, что искать.
  Программа сама всё посчитает — удаление начнётся только когда вы нажмёте кнопку.
  Тест можно пройти заново: «Тест-мастер» внизу слева.

РАЗДЕЛЫ
  Обзор              — 3D-ноутбук с вашим диском на экране, сколько можно освободить.
  Очистка системы    — 112 категорий: Windows, браузеры, Telegram, Discord, Steam, Epic,
                       Roblox, Minecraft, Spotify, драйверы, программы для разработки…
                       Показываются только те программы, что у вас установлены.
  Мусор и копии      — временные файлы, копии «файл (2)», «Копия», «Copy of», «копія»,
                       «Kopie» и т.д. на 25+ языках, пустые папки, битые ярлыки.
  Дубликаты          — одинаковые файлы в разных папках, сгруппированы; вы выбираете,
                       какую копию оставить. Хотя бы одна копия всегда остаётся.
  Бесполезные файлы  — файлы, которые не открывались дольше N дней (фильтр по сроку,
                       размеру и типу).
  Старые игры        — игры, в которые давно не заходили (Steam, Epic, GOG, Ubisoft, EA,
                       Battle.net, Riot, Xbox…). Удаление идёт через сам лаунчер.
  Анализ места       — 3D-карта папок: что занимает больше всего.
  Диски              — тип (SSD/HDD), модель, состояние, оптимизация и проверка.
  Результаты         — сколько места освободила программа, по дням и по категориям.

ВАЖНО
  • Галочка «Пробный прогон» — показывает, сколько освободится, ничего не удаляя.
  • Кэши, логи, Корзина и журналы событий удаляются безвозвратно.
    Найденные файлы (мусор, дубликаты, бесполезные) по умолчанию уходят в Корзину.
  • Кэши для разработчиков (Gradle, NuGet, Playwright и т.п.) потом скачаются заново —
    включайте их, только если понимаете зачем.
  • Для журналов событий, Windows Update, Prefetch и оптимизации диска нажмите
    «Права администратора» внизу слева.
  • История и настройки хранятся в app\cleaner_data.json рядом с программой.
